# OnDoTut Architecture

> Single Source of Truth for the OnDoTut platform.

This repository contains the complete architecture, engineering documentation and technical specifications of the OnDoTut project.

## Purpose

The repository defines:

- Product Vision
- Architecture Principles
- Architecture Decision Records (ADR)
- Module Specifications
- API Specifications
- Security Architecture
- Data Model
- Development Standards
- Roadmap

This repository does NOT contain application source code.

Source code is developed according to the specifications defined here.

---

## Engineering Principles

1. Architecture before implementation.
2. Every important decision must have an ADR.
3. Documentation is part of the product.
4. Core evolves through extension, not modification.
5. Vendor-independent architecture.
6. API First.
7. Security by Design.
