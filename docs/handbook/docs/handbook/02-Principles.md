# Architecture Principles

## AP-001 Workspace First

Workspace is the primary object of the platform.

---

## AP-002 Modular First

Every feature exists as an independent module.

---

## AP-003 API First

Every capability must be accessible through API.

---

## AP-004 Vendor Independence

Vendor-specific logic is isolated inside connectors.

---

## AP-005 Core is Forever

Core changes only when absolutely necessary.

Platform grows by extension.

---

## AP-006 Security by Design

Security is part of architecture.

Not an optional feature.

---

## AP-007 Documentation First

Documentation precedes implementation.

---

## AP-008 Architecture Before Code

Every implementation starts with architecture.

Not with source code.
